Reviews

Use Reviews to manage Change Requests submitted by users for cloud recipes you maintain.

Accessing Reviews

Click Reviews in the sidebar. A numeric badge shows pending change requests.

Change Request Lifecycle

pending → ai_reviewed → approved → merged
                      ↘ rejected
                      ↘ stale
                      ↘ conflict
Status Meaning
Pending Newly submitted and waiting for review.
AI Reviewed Summarized and prioritized by AI triage.
Approved Approved by a maintainer or admin; ready to merge.
Rejected Declined by a reviewer.
Merged Applied to the cloud recipe.
Stale Target recipe changed after the request was submitted.
Conflict Proposed edits conflict with the current recipe version.

Maintainer Permissions

  • Admins: Review, approve, reject, and merge change requests across all cloud recipes.
  • Maintainers: Authors of approved cloud recipes gain maintainer permission on their recipes to review and merge community change requests.

AI Triage and Auto-Merge

When a user submits a change request, rolv runs automated AI triage to produce:

  • Summary: Plain-language overview of the proposed change.
  • Priority: High, Medium, or Low urgency based on bug severity, data correctness, or documentation impact.
  • Duplicate Check: Flags requests that repeat earlier change requests on the same recipe.
  • Reasoning: Short note explaining the assessment.

(Security risk scanning and automatic quarantine run on recipe submissions and updates, described in Recipes.)

Reviewing a Change Request

  1. Click a change request to expand it.
  2. Read the AI assessment and inspect the diff view.
  3. Add an optional review comment.
  4. Select an action:
Action Use When
Approve The proposed changes are valid.
Reject The request should not be applied.
Merge Apply an approved request to the cloud recipe.
Auto-merge Let AI merge a stale change request against the newer recipe version.

Contribution Types

  • Troubleshooting only: Updates troubleshooting.md with observed errors and fixes.
  • Full recipe: Updates workflow scripts, graph structure, environment files, or documentation.
