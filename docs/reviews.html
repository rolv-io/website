Reviews

The Reviews panel lets you manage Change Requests — contributions submitted by other users to recipes you maintain.

Accessing Reviews

Click Reviews in the sidebar. A badge shows the count of pending change requests.

Change Request Lifecycle

pending → ai_reviewed → approved → merged
                      ↘ rejected
                      ↘ stale
                      ↘ conflict
Status Meaning
Pending Just submitted, awaiting review
AI Reviewed The AI has analyzed and commented on the contribution
Approved A reviewer has approved it (ready to merge)
Rejected A reviewer declined the contribution
Merged Changes have been applied to the recipe
Stale The recipe has changed since this request was submitted
Conflict The proposed changes conflict with the current recipe

Maintainer Permissions

  • Admins: Have full review and merge permissions across all platform recipes.
  • Maintainers: When an author's recipe is approved, they gain Maintainer Status on that recipe, allowing them to review, approve, and merge Change Requests submitted by other community members.

AI Assessment & Security Risk Scanning

Each change request is automatically analyzed by AI and passed through an automated Security Risk Scanner, which provides:

  • Summary comment — What the contribution does and potential impacts
  • Security & Malicious Code Warning — Automatically flags unsafe shell execution (rm -rf /, curl | bash) or un-sanitized code. High-risk requests are automatically quarantined.
  • Priority — High, Medium, or Low urgency

Reviewing a Change Request

  1. Click a change request to expand it
  2. Read the AI assessment
  3. Review the diff view showing proposed changes
  4. Optionally add a comment
  5. Choose an action:
Action When to use
Approve The contribution looks good
Reject The contribution isn't suitable
Merge Apply approved changes to the recipe (only available after approval)
Auto-merge Let the AI merge stale contributions automatically

Contribution Types

Users can submit two kinds of contributions:

  • Troubleshooting only — Just the troubleshooting.md file with error fixes and workarounds
  • Full recipe — Complete recipe changes including code, workflow, and documentation
