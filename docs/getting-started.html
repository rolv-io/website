Getting Started

What rolv Does

rolv pairs AI agents with local and remote execution tools for scientific research. You can ask questions in plain language or edit code directly.

Main Capabilities

  • Literature and Data Search: Search PubMed, GEO, ClinicalTrials.gov, patents, and the web with direct source links.
  • Data Analysis: Attach CSV, TSV, Parquet, RDS, Excel, PDF, and image files. The agent writes scripts, runs analyses, and builds figures.
  • Code Execution: Run Python, R, and Bash code in isolated environments on your computer or over SSH.
  • Chat and Graph Workflows: Start in Chat View for fast exploration. Convert working analyses into visual pipelines in Graph View.
  • Recipes: Save pipelines as reusable templates, import existing pipelines, and use recipes from the Cloud Library.

Typical Tasks

  • Differential gene expression analysis (DESeq2, edgeR)
  • Single-cell RNA-seq clustering and cell annotation
  • Sequencing quality control (QC) pipelines
  • Literature synthesis with parallel batch research across gene or drug lists (see Graph View — Research Nodes)
  • Snakemake and script-folder pipeline imports

Signing In and Accounts

Sign in with Google or an email and password.

If you register with email and password, you must verify your email address before the app opens:

  1. Check your inbox and spam folder for an email from noreply@rolv.io.
  2. Open the verification link in that email.
  3. Click I’ve verified in rolv. If needed, click Resend verification email.

If you forget your password, click Forgot password? on the sign-in screen. Reset emails also come from noreply@rolv.io. Google sign-in accounts are already verified.

Account Types

  • Free Account: Run local analyses, use your own API keys in Settings, and browse the Cloud Library. Includes 1 remote compute slot.
  • Academic Account (🎓): Assigned automatically for recognized university and research-institute email addresses. Adds Cloud Library recipe downloads, recipe publishing, daily Cloud library searches allowance, and 3 remote compute slots.

Starting a Chat

On the Welcome screen, click an example prompt or enter your own request in the input box at the bottom. Press Enter to send. Press Shift+Enter to insert a new line.

Working Directory

rolv does not require a project folder for every message. Literature search and general questions work without a folder.

When a tool must read files or run code on disk, rolv shows Choose a project folder:

  • Empty rolv folder: Uses a managed folder at ~/.rolv/sessions/<session-id>. Copy your input files there.
  • Folder that already has my data: Uses an existing folder on your computer. Output files write to the same folder.

Click Ask later to skip folder selection until a disk tool runs. Click the folder icon in the chat header to select or change the folder at any time.

The Sidebar

Use the sidebar to switch views, manage sessions, and open tools:

Control Function
Chat Start a new chat session.
Graph Start a new empty graph pipeline.
Recipes Open the Local Library and Cloud Library.
Reviews View pending change requests for recipes you maintain.
Search bar Search chats, graphs, and messages.
Pinned Keep important sessions at the top of the list.
Recent Open recent sessions, sorted newest first.

Session Actions

Move the pointer over any session in the sidebar to see these icons:

  • Pin / Unpin (📌): Move a session to or from the Pinned list.
  • Delete (🗑️): Permanently delete the session from local storage.

When you click a session, rolv opens the last view (Chat or Graph) you used for that session. New sessions receive a short title after the first real message or graph edit.

Sidebar Controls and Footer

  • Click the panel icon at the top-right of the sidebar to collapse it. Click the floating panel icon at the top-left to expand it again.
  • Settings (⚙️): Open token usage, walkthroughs, execution settings, and API settings.
  • Send Feedback & Feature Requests (💬): Open the feedback dialog to send bug reports or feature ideas directly to the rolv team.
  • Documentation (?): Open this manual inside rolv.
  • Theme toggle (☀️ / 🌙): Switch between light mode and dark mode.
