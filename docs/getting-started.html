Getting Started

What Can rolv Do?

rolv is an agentic research platform — it pairs you with AI agents that can autonomously search scientific literature, analyze your data, execute code, and interpret results. Think of it as a research assistant that can actually run experiments, not just talk about them.

Core Capabilities

🔬 Scientific Literature & Data Discovery rolv agents can search PubMed, GEO (Gene Expression Omnibus), and the open web to find relevant papers, datasets, and protocols. Results are summarized and cited, so you always know where information came from.

📊 Data Analysis & Interpretation Upload your data (CSV, TSV, Parquet, RDS, Excel, images, PDFs) and ask the agent to analyze it. It writes and executes code, produces plots, runs statistical tests, and interprets the results — all in a conversational flow.

💻 Code Execution rolv runs Python, R, and Bash scripts in isolated sandbox environments. Dependencies are auto-installed. You can execute code locally on your machine or remotely via SSH on a powerful server.

🤖 Two Ways to Work

Mode Best for Description
Chat View Quick questions, exploration A conversational interface — ask a question, get analysis back. Fast and flexible.
Graph View Reproducible pipelines, complex workflows A visual DAG (directed acyclic graph) where each node is a processing step. Gives you granular control over execution order, inputs/outputs, and error handling.

The Chat View is the fastest way to get started. When your analysis grows complex, you can convert any chat into a Graph with one click — preserving all your work while gaining reproducibility and fine-grained control.

📦 Recipes & Community Workflows can be saved as Recipes — reusable pipeline templates that package code, environment specs, and documentation into a shareable bundle. You can:

  • Browse and run recipes built by the community
  • Build your own recipes from any graph pipeline
  • Share improvements back — when you fix an issue in a community recipe, rolv can automatically contribute the fix upstream

Recipes do not include your data files. To try a pipeline first, open the Data Input node, expand Test data, pick R, Python, or Bash, and click Starter. Rolv writes a short script. A comment above each sample file says what that file should contain. The script ends by writing test_input.json. Click Generate Data to create the files, copy those values onto the input fields, and save input.json for the pipeline. See Graph View — Test data.

What Kinds of Tasks?

rolv is designed for scientific and data-intensive work. Some examples:

  • Differential gene expression analysis (DESeq2, edgeR)
  • Single-cell RNA-seq clustering and annotation
  • Quality control pipelines for sequencing data
  • Literature reviews with automated summarization. For a list of genes or drugs, use research nodes with Batch iteration across items (ForEach), or have a compute node collect the papers and a research node interpret them (see Graph View — Research nodes).
  • Statistical modeling and visualization
  • Bioinformatics pipeline construction (Snakemake import is supported; it uses many tokens and is not failsafe)

Tip: You don't need to be a programmer. Describe what you want in plain language, and the agent writes and runs the code for you. But if you are a programmer, you have full access to edit every line.

Signing In & Tiers

When you first open rolv, sign in with Google or email/password.

Email/password accounts must verify email before the app opens. After you register, check your inbox (and spam) for a message from noreply@rolv.io. Use Resend verification email, then I’ve verified. Google sign-in is already verified.

Forgot password? On the sign-in screen, that link sends a reset email from the same address (noreply@rolv.io). Check spam if it does not appear within a minute.

Your account tier determines quotas and feature capabilities:

  • Free Tier: Local execution with custom API keys. You can browse the Cloud Library; downloading recipes requires Academic or Pro.
  • Academic Tier (🎓): Assigned when you sign up with an institutional email that Rolv recognizes as academic (university or research institute). Includes 5 active recipe workspace slots, 200 daily Cloud RAG queries, and access to Publish-to-Earn rewards.
  • Pro & Pro+ Tiers: Unlimited recipe workspace slots, unlimited Cloud RAG queries, and monthly compute credit allocations.

Your First Chat

After logging in, you'll see the Welcome Screen with example prompts like:

  • Analyze my RNA-seq data
  • Help me cluster single-cell
  • Build a QC pipeline
  • Find differentially expressed genes

Click any prompt or type your own in the input box at the bottom. Press Enter to send.

Working Directory

Rolv does not ask for a folder on every message. Literature and web search work without one. When a tool needs disk access (running code, listing or reading workspace files, inspecting plots, or proposing graph changes), you will see Choose a project folder:

  • Empty Rolv folder — ~/.rolv/sessions/<session-id>. Copy or move your data in after choosing this.
  • Folder that already has my data — Pick the directory where your tables already live. Outputs go there too.

You can postpone with Ask later; Rolv will ask again when a disk tool needs a folder. Change it later with the folder icon in the chat header.

The Sidebar

The sidebar is your navigation hub:

Element What it does
Chat button Start a new chat conversation
Graph button Create a new empty graph pipeline
Recipes button Open the recipe library
Reviews button View community change requests
Search bar Search across all chats, graphs, and messages
Pinned section Sessions you've pinned for quick access
Recent section Your latest sessions, newest first

Session Actions

Hover over any session in the sidebar to reveal:

  • 📌 Pin/Unpin — Keep important sessions at the top
  • 🗑️ Delete — Permanently remove the session

Click a session title to open it (unnamed sessions get a short auto-title after the first real message or graph content). Rolv restores the last Chat or Graph view you used for that session. If you have never opened it, graph-only sessions start in Graph View and conversational sessions start in Chat View.

Sidebar Controls

  • Collapse — Click the panel icon (top-right of sidebar) to hide it
  • Expand — Click the floating panel icon (top-left) when sidebar is hidden

Dark & Light Mode

Click the sun/moon icon at the bottom of the sidebar to toggle between dark and light themes. Your preference is saved automatically.
