Welcome to rolv

rolv is a desktop app for scientific data analysis, reproducible pipelines, and computational research.

Documentation Pages

  • Getting Started — Sign in, choose a working folder, and use the sidebar.
  • Chat View — Run analyses in chat, attach files, and approve code execution.
  • Graph View — Build and run visual pipelines with compute, research, and data nodes.
  • Recipes — Browse, run, edit, import, and publish workflow templates.
  • Reviews — Review community change requests for recipes you maintain.
  • Settings — View token usage, manage walkthroughs, set up execution tools, and configure API providers.
  • Troubleshooting — Fix common sign-in, environment, execution, and search problems.

Core Terms

Term Meaning
Session A chat workspace or graph pipeline workspace.
Graph A directed acyclic graph (DAG) of connected processing steps.
Node One step in a graph: a compute script, an AI research step, or a data input/output block.
Recipe A reusable pipeline template with code, environment files, and documentation.
Working Directory The local folder where scripts run and output files save.

Getting Help

  • Click the graduation cap icon (🎓) in Chat View or Graph View to send a question to a human expert.
  • Click the speech bubble icon in the sidebar footer to send general product feedback or feature requests.
  • Report software bugs on GitHub Issues.
